# 2026-09-29 메일 — 과제 A 자료 (구조만)

제출자가 메일로 보낸 과제 A 자료입니다(대표 전달). **원본 파일은 저장소에 넣지 않았습니다.**
품번·회사명·협력사명·양식 번호·접수 번호·작성자 서명이 들어 있고, 도면은 제출자가 사외 반출이 안 된다고 한 자료입니다.
아래는 형식과 구조, 이 도구로 한 검증 결과만 적은 것입니다. 저장소의 예시 파일(`samples/`)은 같은 칸 배치로 새로 만든 가상 값입니다.

## 받은 파일

| 구분 | 수 | 형식 |
|---|---|---|
| CMM 성적서 | PDF 5건 | ZEISS CALYPSO 7.4 표준 성적서(PiWeb 출력), A4, 글자 층 있음. 1쪽 4건, 2쪽 1건 |
| 도면 | PDF 1건 | CATIA 출력 A1, 글자 층 없음(치수 글자도 선). 위 성적서 1건과 짝 |
| 측정실 성적서 | 엑셀 1건 | 시트 4개(전체 5쪽 중 2~5쪽), 1쪽에 측정 위치 그림 1장 |

## CMM 성적서(CALYPSO) 구조

머리(왼쪽·오른쪽 두 칸):

```
Part name        <품번>                    Last 1 measurements
Drawing number                              Part ident            <번호>
Order number                                Time/Date             <날짜 시각>
Variant                                     Run                   <측정 범위>
Company                                     No. measured values   <측정 줄 수>
Department                                  No. values: red       <불합격 수>
CMM 타입         <장비 모델>                측정 시간             <시간>
CMM No.          <장비 번호>
Operator         <작업자>
```

표:

```
Name              Measured value  Nominal value  상한공차  하한공차   편차     +/-
<요소>_직경          32.971 mm        33.000     -0.021    -0.036   -0.029
<요소>_직경          22.018 mm        22.000      0.000    -0.020    0.018   0.018   ← +/- 는 불합격일 때만
<요소>_직경          68.049 mm        68.000                          0.049           ← 공차 없음(참고 측정)
원추 반각1           3° 11' 5"      3° 30' 0"   0° 0' 0"  -0° 30' 0" -0° 18' 55"   ← 각도는 도·분·초
위치도1              0.138 mm                                                     ← 기준값 없는 요약 줄
Section View A-A                                                                  ← 구역 제목 줄
```

- 항목명: `원1_직경`, `캘리퍼 거리1_X`, `동심도_A`, `원통도1`, `반경 방향 원주 흔들림2`, `축 방향 원주 흔들림1`, `대칭 점1_대칭거리`, `위치도1^3`, `요소 사이의 각도1(5)` 등 — 요소 종류를 이름에서 알 수 있습니다.
- **측정번호 칸이 없습니다.** 도면 풍선 번호와 잇는 열이 없어 기준값·공차·종류로 짝을 찾아야 합니다.
- 형상·위치공차 줄은 기준값 0, 상한공차 = 공차, 하한공차 0 으로 찍힙니다. 공차가 0/0 인 흔들림 줄도 있습니다(측정값이 곧 초과량).
- 2쪽 성적서는 2쪽 위에 머리 일부(Part name·Order number·Part ident·Operator·Time/Date)와 표 머리글이 다시 찍힙니다.
- 구역 제목 한 건은 원문이 「Section Veiew A-A」(오타)입니다.

## 도면 구조

- 치수: Ø 치수 + 위·아래 공차, 끼워맞춤 등급(g6·f6), 각도(도 + 분 공차), 길이 치수.
- 형상·위치공차 틀: ◎(동심도) Ø값 + 데이텀, ⌭(원통도), ↗(흔들림) + 데이텀.
- 표제란: 회사·협력사·작성·검도·승인 서명, 재질, 도번. (저장소에 옮기지 않음)

## 측정실 성적서 엑셀 구조

```
의뢰부서 …  접수번호 …(n/5)
품명 …      도면번호 -
구분 | 항 목 | 측정위치     | 측정값 …                 (단위: ㎜)
     |       | 표준치       | 위치1 | 위치2 | … | 위치5      ← 축 방향 측정 위치(mm)
G1   | 내경  | Ø기준값      | 값 …                          ← 표준치 칸: 「Ø기준값 줄바꿈 [+상/하]」
     |       | [+0.005/0]   |
     | 진원도 | 0.004       | 값 …                          ← 숫자 칸 = 한계
     |       | 측정위치 ⇒   | 위치6 | 위치7 | 위치8
G1   | 내경  | …            | 값 …
     | 진원도 | 0.004       | 값 …
     | 원통도 | 0.008       | 값(보어 전체 하나)
     | 진직도 | 0.004       | 값(보어 전체 하나)
…
의견 / 측정 방법(필터·스캐닝 속도·프로브 반경·평가 방식)
<양식 번호>                                  <회사명>
```

- 시트마다 보어 2~3개(G1~G10).
- 마지막 시트 G10 의 마지막 줄 항목명이 「진원도」입니다. 다른 9개 보어는 같은 자리가 모두 「진직도」라 오기로 보입니다(확인 요청).
