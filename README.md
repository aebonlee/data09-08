## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-08/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 데이터가 비어 있습니다. **「예시 데이터 불러오기」** 를 누르면 가상 부품(EX-BRKT-100)·가상 도면·가상 협력사 데이터가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

쓰는 순서(과제 A): **검사 건** 등록 → **치수 기준표** 입력(붙여넣기·파일) → **측정결과**(CMM 파일 + 열 지정, 수기 입력) → **판정 결과**(OK / NOK / 확인필요, 성적서 Excel) → **도면 보기**(핀 찍기, 판정 색 표시)

- 파일은 서버로 보내지 않습니다. 도면·측정값은 **이 브라우저(localStorage)에만** 저장됩니다. 보관·이동은 「설정·데이터」의 엑셀 백업으로 합니다(도면 이미지는 백업에 들어가지 않으니 원본을 다시 올립니다).
- 예시 파일(모두 가상): `samples/예시데이터_치수기준표.xlsx`(시트 2개: 상·하한 두 칸 / 공차 한 칸) · `예시데이터_CMM결과.csv` · `예시데이터_수기측정.csv` · `예시데이터_도면.svg` · `예시데이터_설비목록.csv` · `예시데이터_일일점검.csv` · `예시데이터_점검기준값.csv`
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

**과제 A — 초도품 치수검사 (1차 개발 대상)**

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 검사 건 등록 | 완료 | 품번·Rev·LOT·검사일·업체·검사자, 여러 건 목록·선택·삭제, 「같은 품번 새 LOT」(기준표·도면·핀 복사) |
| 치수 기준표 입력 | 완료 | 표에서 직접 입력·수정, 엑셀 붙여넣기, xlsx·csv 가져오기 + 열 지정. 「±0.1」「+0.05/0」 같은 한 칸 공차 표기를 상·하한으로 나눔. 줄마다 하한~상한 바로 표시 |
| CMM 결과 가져오기 | 완료 | xlsx·csv(UTF-8/EUC-KR) → 머리행·열 지정(측정번호·항목명·측정값·단위, 머리글로 자동 추정) → 표준 형식. 장비별 열 지정 템플릿 저장·재사용. 바꾸기/덧붙이기 선택 |
| 자동 판정 | 완료 | 상·하한 = 기준값 + 공차, 경계값 포함 OK. ± 공차·단측공차, 단위 변환(mm·cm·µm·inch, deg), 기준표 자리수로 판정 전 반올림(설정, 기본 끔) |
| 확인필요 분류 | 완료 | 측정값 없음·기준표에 없는 측정·숫자 아님·단위 불일치·공차 없음/뒤집힘·항목번호 중복·같은 항목 OK/NOK 혼재 → 판정하지 않고 확인필요 + 사유 |
| 도면 오버레이 | 완료 | PNG·JPG·SVG 도면 올리기 → 항목 고르고 도면을 눌러 핀 찍기(다음 항목으로 자동 이어짐) → 녹/적/황 핀, 핀을 누르면 기준값·공차·측정값·편차. PDF 직접 읽기는 다음 단계 |
| 통합 검사결과 표 | 완료 | 치수별 기준/공차/하한~상한/측정/편차/이탈량/출처/판정/사유, 판정별 거르기, 줄을 누르면 도면에서 그 항목 |
| 검사성적서 출력 | 완료(범용 양식) | Excel(성적서·치수기준표·측정원본 시트) + CSV. 회사 양식 맞춤은 양식을 받은 뒤 |
| 수기 측정값 | 일부 | 손으로 입력·붙여넣기(출처 「수기」). 사진 OCR 은 2단계 |
| 수기 측정표 OCR · 도면 치수 자동 인식 · 좌표/복합 매칭 | 다음 단계 | 2·3단계 (1단계는 항목번호 직접 매칭 + 번호 없을 때 항목명 매칭) |
| 예외 검토 화면(수정 이력) · 대시보드·이력 검색 · 다국어·권한 · SPC/알림/CAPA | 다음 단계 | 2·3단계 |

**과제 B — 협력사 일일점검 (기획서 8장 1단계에 적힌 범위만)**

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 점검 데이터 표 | 완료(표 입력) | 설비 목록·점검 데이터·관리 기준값을 xlsx·csv·붙여넣기 + 열 지정으로 넣음 |
| 등록 현황판 | 완료 | 점검일별 협력사 등록 설비 수 / 전체, 설비별 등록·미등록 |
| 규칙 기반 이상 검출 | 완료 | 판정 빈칸, 판정 이상 기입(×·NG 등), 측정값 미기입·숫자 아님, 관리 기준값 이탈, 같은 값 N회 연속(N 은 사용자 설정, 비우면 검사 안 함 — 「확인 필요」로만 표시). CSV 내려받기 |
| 협력사 전용 업로드 링크 · 동일 사진 검출 · 점검표 OCR · 메일 알림 · Score | 다음 단계 | 서버·OCR 이 필요해 2단계 이후 |

**과제 C — 용접누락 검출**: 이번 1단계에서는 만들지 않았습니다. 정상/누락 라벨이 붙은 용접 사진 세트가 먼저 있어야 합니다(기획서 8장·10장).
