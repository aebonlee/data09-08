## 폐쇄망 사용법 (사내망·인터넷 없는 PC)

**이 화면은 어떤 데이터도 외부로 보내지 않습니다.** 서버 없이 브라우저만으로 도는 파일 묶음이라 사내 PC 에서 그대로 쓸 수 있습니다.

1. 인터넷이 되는 PC 에서 이 저장소 화면의 **Code → Download ZIP** 으로 받습니다.
2. 회사 반입 절차에 따라 ZIP 을 사내 PC 로 옮기고 압축을 풉니다.
3. 폴더의 `index.html` 을 크롬·엣지로 엽니다(주소가 `file://` 로 시작). 인터넷 연결 없이 모든 기능이 동작합니다.
4. 「설정·데이터」에서 **폐쇄망 모드**가 켜져 있는지 확인합니다(기본 켬). 화면 위 초록 띠에 「이 화면은 어떤 데이터도 외부로 보내지 않습니다」가 보이면 됩니다.
5. 도면·측정 데이터는 **그 PC 브라우저 저장소(localStorage)와 내가 내려받은 파일(성적서 Excel·전체 백업)에만** 남습니다. 옮길 때는 「엑셀로 전체 내보내기」 파일을 사내 경로로 옮깁니다.

어떻게 보장하나:
- 외부 CDN 0건 — 엑셀 라이브러리(SheetJS)도 `vendor/` 에 들어 있고, 그 안에도 네트워크 요청 코드가 없습니다.
- PDF 해석 도구(pdf.js, Apache-2.0)도 `vendor/pdfjs/` 에 있습니다. PDF 는 파일 바이트로만 넘기고 주소·글꼴표 경로를 주지 않아 요청이 나가지 않습니다(테스트가 호출부를 검사).
- 코드에서 외부로 요청하는 곳은 폐쇄망 모드를 껐을 때의 「AI 읽기」(`js/ai.js`) 한 곳뿐이며, 폐쇄망 모드에서는 버튼이 숨겨지고 함수도 요청을 거부합니다.
- `index.html` 의 Content-Security-Policy(`connect-src https:`)가 암호화되지 않은 주소 연결을 브라우저 차원에서 막습니다. AI 주소를 설정에서 고를 수 있게 되어(2026-09-29) OpenAI 한 곳에서 https 전체로 넓혔습니다. 사내 웹서버에 올릴 때는 아래 「사내 웹서버에 올리기」 4번처럼 회사가 허용한 주소 하나로 좁히거나 `'none'` 으로 막으십시오.
- `node test/logic.test.mjs` 의 「폐쇄망」 검사가 모든 파일을 훑어 네트워크 요청 코드가 `js/ai.js` 의 한 곳뿐인지 확인합니다. 직접 확인하려면 개발자 도구(F12) → 네트워크 탭을 연 채로 써 보십시오.

## 사내 웹서버에 올리기 (여러 명이 같은 주소로 쓰기)

2026-09-29 수강생 답변: 「사내 ZIP 반입은 가능합니다. 다만, 웹서버에 올려 여러 명이 사용하면 좋을 듯 합니다.」

이 도구는 **서버 프로그램이 필요 없는 정적 파일 묶음**(HTML·CSS·JS·엑셀/PDF 라이브러리)이라, 사내 웹서버의 웹 폴더에 그대로 복사하면 됩니다. 빌드·설치·DB 없이 동작합니다.

1. 이 저장소를 ZIP 으로 받아(**Code → Download ZIP**) 반입 절차대로 사내로 옮기고 압축을 풉니다.
2. 폴더 안의 `index.html`·`favicon.svg`·`css/`·`js/`·`vendor/`(·예시가 필요하면 `samples/`)를 웹서버 폴더에 복사합니다. `docs/`·`test/`·`scripts/`·`supabase/` 는 올리지 않아도 됩니다.
   - **IIS**: 새 사이트(또는 가상 디렉터리)의 실제 경로를 그 폴더로 지정, 기본 문서에 `index.html`. 파일 형식은 `.html`·`.css`·`.js`·`.svg`·`.xlsx`·`.csv`·`.txt`·`.pdf` 뿐이라 MIME 설정을 따로 더할 것이 없습니다(`.csv` 예시를 받으려면 `text/csv` 확인).
   - **nginx**: `location /qc/ { alias /srv/qc/; index index.html; }`
   - **Apache**: `Alias /qc /srv/qc` + `<Directory /srv/qc> Require all granted </Directory>` (또는 DocumentRoot 아래에 복사)
3. 사내 주소(예: `http://qcserver/qc/`)를 열어 확인합니다. 모든 계산·PDF·엑셀 처리는 **각자의 브라우저 안에서** 돌고 웹서버는 파일만 내려줍니다 — 도면·측정 파일이 웹서버로 올라가지 않습니다.
4. 보안 정책을 회사에 맞춥니다. `index.html` 머리(`<head>`)의 `Content-Security-Policy` 에서 `connect-src` 를:
   - 과제 A 처럼 외부로 아무것도 보내지 않을 때: `connect-src 'none'`
   - 회사가 허용한 AI 주소 하나만 쓸 때: `connect-src https://허용된-주소`
   - 사내 LLM 서버가 http 뿐일 때: `connect-src http://10.x.x.x:포트` (그 주소만)
   - 웹서버가 같은 헤더(`Content-Security-Policy`)를 내려주게 설정해도 됩니다. 둘 다 있으면 더 엄한 쪽이 적용됩니다.
5. 새 판으로 바꿀 때는 폴더를 통째로 덮어씁니다. 데이터는 브라우저에 있으니 덮어써도 지워지지 않습니다(주소가 같아야 합니다).

**지금 한계 — 데이터는 아직 사람마다 따로입니다.** 같은 주소로 열어도 검사 건·기준표·점검 데이터는 **각자 브라우저 저장소(localStorage)** 에 남아 서로 보이지 않습니다. 당장은 「설정·데이터 → 엑셀로 전체 내보내기 / 가져오기」로 주고받습니다.

**여럿이 같은 데이터를 보려면(다음 단계)** — `supabase/schema.sql` 의 표 구조를 쓰는 DB 연결이 필요합니다. 표·보안 규칙은 만들어 두었지만 **화면(`js/store.js`)은 아직 DB 를 읽고 쓰지 않습니다.** 붙일 때 바뀌는 것:

- **DB 위치**: 외부 Supabase(클라우드)는 도면 반출 불가 원칙과 맞지 않으므로, 사내에서는 **Supabase 자체 설치(self-hosted, Docker)** 또는 **사내 PostgreSQL + REST 서버(PostgREST 등)** 를 둡니다. Supabase 자체 설치에는 `schema.sql` 이 그대로 들어갑니다. 순수 PostgreSQL 이면 보안 규칙이 쓰는 `auth.uid()`(로그인한 사람)·`anon`/`authenticated` 역할을 사내 계정 방식에 맞게 바꿔야 합니다.
- **로그인**: 지금 `schema.sql` 의 보안 규칙은 **만든 사람만** 자기 행을 봅니다. 팀이 함께 보려면 「부서(팀) 단위로 보기」 규칙과 역할(검사자·승인자·협력사)을 더해야 합니다.
- **도면·사진**: 브라우저 저장 대신 사내 저장소(Supabase Storage 비공개 버킷 또는 파일서버)에 두고 DB 에는 경로만.
- **화면**: `js/store.js` 에 「브라우저 저장 / 사내 DB」 선택을 두고, DB 쪽은 불러오기·저장을 서버 호출로 바꿉니다. `index.html` 의 `connect-src` 에 사내 DB 주소를 더합니다.
- 이것은 회사가 DB 서버를 둘 수 있는지(전산팀) 정해진 뒤에 붙이는 것이 맞아 이번에는 만들지 않았습니다(기획서 14장).

## AI 읽기 — 다른 AI 주소 쓰기 (과제 B)

2026-09-29 수강생 질문: 「과제 B는 중국 AI로 돌려도 되는지요?」

- **써도 되는지는 회사 보안 부서가 정할 일입니다.** 저희가 허락할 수 있는 것이 아닙니다. 판단 재료: AI 로 나가는 것은 **협력사 설비 점검표 사진 한 장과 요청문**이고, 사진에는 **협력사명·점검자 이름·서명**이 찍혀 있습니다. 서명·이름은 가리거나 잘라낸 사진으로 읽히기를 권합니다. 도면·사내 측정표(과제 A)는 어떤 AI 로도 보내지 마십시오.
- 기술적으로는 됩니다. 「설정·데이터」에서 폐쇄망 모드를 끄면 **AI 주소(OpenAI 호환 base URL)·모델 이름·API 키**를 적을 수 있습니다. 비우면 OpenAI 로 보내고, **OpenAI 호환 주소를 제공하는 서비스**나 **사내 설치형 LLM 서버**의 주소를 적으면 그쪽으로 보냅니다(사진을 읽을 수 있는 모델이어야 합니다). 요청 형식은 `…/chat/completions` 에 사진을 붙이는 OpenAI 형식입니다.
- 폐쇄망 모드(기본 켬)에서는 주소를 적어도 요청을 만들지 않습니다(`js/ai.js` `buildRequest`, 테스트로 확인).
- 협력사가 중국 현지에서 직접 쓰는 경우의 접속성(중국 안에서 어느 주소가 열리는지)은 확인하지 못했습니다. 실제 서비스로 시험해 보셔야 합니다.
