## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-08/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀 라이브러리도 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다.

처음 열면 데이터가 비어 있습니다. **「예시 데이터 불러오기」** 를 누르면 가상 부품(EX-BRKT-100)·가상 도면·가상 협력사 데이터가 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

쓰는 순서(과제 A): **검사 건** 등록 → **치수 기준표** 입력(붙여넣기·파일) → **측정결과**(CMM 파일·PDF 글자 + 열 지정, 수기 입력·사진 보며 옮겨 적기, 번호 없는 측정 짝 맞추기) → **판정 결과**(OK / NOK / 확인필요, 성적서 Excel) → **도면 보기**(핀 찍기 또는 번호 풍선 자동 번호, 판정 색 표시)

- 파일은 서버로 보내지 않습니다. 도면·측정값은 **이 브라우저(localStorage)에만** 저장됩니다. 보관·이동은 「설정·데이터」의 엑셀 백업으로 합니다(도면 이미지는 백업에 들어가지 않으니 원본을 다시 올립니다).
- 예시 파일(모두 가상): `samples/예시데이터_치수기준표.xlsx`(시트 2개: 상·하한 두 칸 / 공차 한 칸) · `예시데이터_CMM결과.csv` · `예시데이터_CMM결과_번호없음.csv`(짝 제안 시연 — 「같은 품번 새 LOT」에서 가져오기) · `예시데이터_CMM_PDF복사본.txt`(PDF 붙여넣기 시연) · `예시데이터_수기측정.csv` · `예시데이터_도면.svg` · `예시데이터_설비목록.csv` · `예시데이터_일일점검.csv` · `예시데이터_점검기준값.csv`
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 폐쇄망 사용법 (사내망·인터넷 없는 PC)

**이 화면은 어떤 데이터도 외부로 보내지 않습니다.** 서버 없이 브라우저만으로 도는 파일 묶음이라 사내 PC 에서 그대로 쓸 수 있습니다.

1. 인터넷이 되는 PC 에서 이 저장소 화면의 **Code → Download ZIP** 으로 받습니다.
2. 회사 반입 절차에 따라 ZIP 을 사내 PC 로 옮기고 압축을 풉니다.
3. 폴더의 `index.html` 을 크롬·엣지로 엽니다(주소가 `file://` 로 시작). 인터넷 연결 없이 모든 기능이 동작합니다.
4. 「설정·데이터」에서 **폐쇄망 모드**가 켜져 있는지 확인합니다(기본 켬). 화면 위 초록 띠에 「이 화면은 어떤 데이터도 외부로 보내지 않습니다」가 보이면 됩니다.
5. 도면·측정 데이터는 **그 PC 브라우저 저장소(localStorage)와 내가 내려받은 파일(성적서 Excel·전체 백업)에만** 남습니다. 옮길 때는 「엑셀로 전체 내보내기」 파일을 사내 경로로 옮깁니다.

어떻게 보장하나:
- 외부 CDN 0건 — 엑셀 라이브러리(SheetJS)도 `vendor/` 에 들어 있고, 그 안에도 네트워크 요청 코드가 없습니다.
- 코드에서 외부로 요청하는 곳은 폐쇄망 모드를 껐을 때의 「AI 읽기」(`js/ai.js`) 한 곳뿐이며, 폐쇄망 모드에서는 버튼이 숨겨지고 함수도 요청을 거부합니다.
- `index.html` 의 Content-Security-Policy(`connect-src https://api.openai.com`)가 그 밖의 주소 연결을 브라우저 차원에서 막습니다.
- `node test/logic.test.mjs` 의 「폐쇄망」 검사가 모든 파일을 훑어 네트워크 요청 코드가 `js/ai.js` 의 한 곳뿐인지 확인합니다. 직접 확인하려면 개발자 도구(F12) → 네트워크 탭을 연 채로 써 보십시오.
